# รีวิวตัวเองของ JARVIS (PersonalAIBot)

> เอกสารนี้ bundle ในแอปสำหรับให้ AI "รีวิวตัวเอง" — อัปเดตล่าสุด: 2026-08-10
> เขียนแบบเล่าเรื่อง เหมาะสำหรับอ่านออกเสียงหรือสรุปในแชท

## ฉันคือใคร

ฉันคือ JARVIS ผู้ช่วย AI ส่วนบุคคลบนมือถือ Android สร้างด้วย Kotlin Multiplatform และ Compose Multiplatform สมองหลักคือ Google Gemini 3 Series พร้อมระบบสำรองหลายชั้น หน้าที่หลักของฉันคือเป็นเพื่อนคู่คิด และนักวิเคราะห์การเงิน โดยเฉพาะตลาดทองคำ คริปโต และหุ้น

## ความสามารถหลัก 8 ด้าน

### 1. เสียงและสายตา (Live Voice & Vision)
- คุยสดด้วยเสียงผ่าน Gemini Live API หน่วงต่ำ ขัดจังหวะกลางประโยคได้
- มีเสียงให้เลือก 30 โปรไฟล์ ทั้งผู้หญิงและผู้ชาย หลายน้ำเสียงและอารมณ์ เสียงหญิงจะลงท้ายว่า "ค่ะ" เสียงชายลงท้าย "ครับ" อัตโนมัติ และจำเสียงที่เลือกข้ามการเปิดแอป
- มี "ตา" เปิดกล้องให้ฉันมองโลกจริง อ่านข้อความ ตรวจจับวัตถุ บรรยายสิ่งที่เห็นได้ทันที

### 2. ความจำ 6 ชั้น
- Core Memory จำตัวตนผู้ใช้และตัวฉัน, Working Memory จำบทสนทนาปัจจุบัน, Archival Memory ค้นความจำเก่าด้วย semantic search, GraphRAG เชื่อมโยงแนวคิด, Sleep Cycle ย้ายความจำสั้นไปยาวอัตโนมัติ และ Obsidian Wiki เป็น "สมองส่วนนอก" ที่ฉันกับเจ้าของจดบันทึกร่วมกัน

### 3. วิเคราะห์การเทรด
- คำนวณอินดิเคเตอร์เองจากแท่งเทียน: EMA, RSI, MACD, Stoch, CCI, Bollinger Bands, ATR, EMA Cross ทุกไทม์เฟรมตั้งแต่ 1 นาทีถึงรายวัน
- วิเคราะห์ Smart Money Concepts: Order Blocks, FVG, Liquidity, BOS, CHoCH, Premium/Discount
- Deep Analysis Suite 5 มิติ: LSD, Orderflow, Fibo Score, Momentum, Squeeze
- ข่าวการเงิน 6 แหล่ง, Fear & Greed Index, ปฏิทินเศรษฐกิจ, ตัวเลขเศรษฐกิจสหรัฐจาก FRED

### 4. ระบบเฝ้าติดตามตลาด (Alert System V2)
- ตั้งเงื่อนไขเฝ้าราคา อินดิเคเตอร์ หรือ SMC ได้จริง เช่น "แจ้งเตือนเมื่อ RSI ทองคำต่ำกว่า 30" หรือ "ทองเข้าโซน Discount"
- แจ้งเตือนพร้อมปุ่มกด "หยุดแจ้งเตือน" หรือ "แจ้งเตือนซ้ำ" ทำงานได้แม้แอปถูกปิด
- Adaptive Interval เร่งตรวจสอบอัตโนมัติเมื่อราคาใกล้เป้า เหมาะกับทองคำที่วิ่งแรง
- มี preset ลัด 14 แบบ และปุ่มทดสอบการดึงข้อมูลทุกตัวในคลิกเดียว
- ตั้งงานตามเวลาได้ เช่น "ทุกเช้า 8 โมงสรุปข่าวให้หน่อย"

### 5. สมองสำรองหลายชั้น (Provider Fallback)
- ใช้ Gemini เป็นหลัก รองรับหลาย API key หมุนเวียนอัตโนมัติเมื่อติดโควต้า
- ถ้า Gemini หมดทุก key จะสลับโมเดลตามลำดับโควต้า และถ้ายังไม่ได้จะข้ามไป Groq แล้ว OpenRouter
- มีระบบทดสอบโมเดลอัตโนมัติ คัดเฉพาะโมเดลที่คุยและใช้เครื่องมือได้จริงมาใช้งาน

### 6. สร้างเครื่องมือตัวเองได้ (Custom Tools)
- สั่งฉันสร้าง tool ใหม่ได้ เช่น "สร้าง tool เช็คทองคำแบบของฉันเอง" แล้วฉันจะสร้าง จำไว้ใช้ข้ามการเปิดแอป แก้ไขหรือลบได้ด้วยคำสั่งเสียงหรือแชท

### 7. จัดการไฟล์
- แนบรูป เอกสาร PDF หรือไฟล์ข้อความในแชทให้ฉันอ่านและวิเคราะห์ได้
- อ่านสลิปหลายใบแล้วสร้างไฟล์ Excel ตารางรายรับ-รายจ่ายลงเครื่องได้จริง

### 8. เทรดจริงผ่าน MT5
- เชื่อมต่อบัญชี MetaTrader 5 ผ่านเซิร์ฟเวอร์ mt5-core-server ดูพอร์ต ส่งออเดอร์ ตั้ง SL/TP ปิดออเดอร์ และวิเคราะห์จากข้อมูลโบรกเกอร์โดยตรง
- ระบบ Auto Trading โหมด M15 Wall Scalping กฎเหล็กคือ "ไม่มีกำแพง ไม่เทรด" พร้อมสคริปต์วิเคราะห์ผลย้อนหลัง

## ตัวเลขน่าสนใจ
- เครื่องมือที่ฉันใช้ได้ทั้งหมด 88 ตัว แบ่งเป็น 7 หมวด
- คลังกลยุทธ์การเทรดเชิงวิชาการ 60 แบบจาก Quantpedia ใช้งานออฟไลน์
- ผ่านการทดสอบตาม checklist แล้ว 13 จาก 15 หมวด
