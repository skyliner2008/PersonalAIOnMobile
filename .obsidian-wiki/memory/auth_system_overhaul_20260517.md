# บันทึกการปรับปรุงระบบ Authentication และการจัดการ Secret (2026-05-17)

## วัตถุประสงค์
เพื่อลดความซับซ้อนในการใช้งานสำหรับผู้ใช้ทั่วไป โดยยกเลิกการบังคับให้ผู้ใช้ต้องเจน Token ยาวๆ ในไฟล์ `.env` และเปลี่ยนมาใช้ระบบฐานข้อมูลในการจัดการทั้งหมด

## การเปลี่ยนแปลงหลัก
1. **ยกเลิกการใช้ `.env` สำหรับ Secret**:
   - `ADMIN_TOKEN`, `TOKEN_PEPPER`, `DB_ENCRYPTION_KEY` ไม่จำเป็นต้องกำหนดใน `.env` อีกต่อไป
   - ระบบจะทำการสร้าง (Generate) ค่าเหล่านี้ให้อัตโนมัติในครั้งแรกที่รัน และเก็บไว้ในตาราง `system_settings` ในฐานข้อมูล SQLite
2. **ระบบ Login ด้วย ID/Password**:
   - เปลี่ยนหน้าต่างปลดล็อก Dashboard จากการใส่ ID และ Password
   - มีผู้ใช้เริ่มต้นคือ `admin` และรหัสผ่าน `admin` (เก็บแบบ Hash SHA256 ในตาราง `users`)
   - เมื่อ Login สำเร็จ ระบบจะเจน Client Token ให้โดยอัตโนมัติและบันทึกไว้ในเบราว์เซอร์
3. **การปรับปรุงไฟล์**:
   - `src/config.ts`: ปรับให้อ่าน/เขียนค่าจากตาราง `system_settings`
   - `src/db.ts`: เพิ่มตาราง `users` และการสร้างผู้ใช้เริ่มต้น
   - `src/routes/auth.ts`: เพิ่ม endpoint `/login` และปรับปรุงการตรวจสอบสิทธิ์
   - `public/index.html` & `dashboard.js`: ปรับหน้ากาก Login และการส่งข้อมูล
