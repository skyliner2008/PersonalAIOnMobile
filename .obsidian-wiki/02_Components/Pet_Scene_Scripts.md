# Pet Scene Scripts (บทฉาก)

ทุกฉากเป็น **เรื่องสั้น 7–9 วินาที** ไม่ใช่พร็อพลอยนิ่ง โครงเดียวกันทุกฉาก:

1. **ตั้งต้น** — ตาปกติ
2. **สังเกต** — ตามอง / เอียงหัว ไปทางที่ของจะมา
3. **ของมา** — พร็อพเคลื่อนเข้าฉากพร้อมเสียง
4. **ลงมือ** — ดวงตาแสดงอารมณ์ตามการกระทำ (กิน เคี้ยว ตกใจ ดีใจ)
5. **จุดพีค** — เอฟเฟกต์ใหญ่ที่สุดของเรื่อง
6. **ปิดฉาก** — ท่าจบค้างไว้ จนระบบคืนสู่ปกติ

เสียงประกอบทุกฉากกำหนดเป็น cue ตามเวลา (มิลลิวินาที) — เล่นจาก `PetSceneEngine` จึงได้ยินทั้ง Engine Rive และ Canvas

สัญลักษณ์: 👀 ดวงตา/หัว · 🎁 พร็อพ · 🌄 ฉาก · 🔊 เสียง (ชื่อ `RobotSound`)

## การนำไปใช้
- Rive: หนึ่งฉาก = หนึ่ง story (`seq`) + พร็อพประกอบฉาก (`Scene*`) ที่มีชิ้นส่วนเคลื่อนไหวแยก ขยับด้วยคีย์เฟรมในเรื่อง; ของที่เปลี่ยนได้ (อาหาร เครื่องดื่ม แล็ปท็อป/หนังสือ) เลือกด้วยช่อง `item`
- แอป: `RobotFaceState.sceneName / sceneItem / sceneId` → `RiveAvatarMapper` เปิด story; `PetSceneSpec.cues` เล่นเสียงตามเวลา; ระยะเวลาฉากตรงกับบท
