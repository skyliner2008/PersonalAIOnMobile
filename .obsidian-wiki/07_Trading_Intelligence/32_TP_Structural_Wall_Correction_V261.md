# V26.1 Structural TP & EA Stability (2026-05-15)

การปรับปรุงประสิทธิภาพระบบวางแผนกำไร (TP) และความเสถียรในการรันโหมด EA-ONLY

## 1. การแก้ไขจุดบกพร่อง TP Overshoot (Bug Fix)
**ปัญหา:** พบออเดอร์ (เช่น ticket 156014081) วาง TP ล้นกำแพงราคาสำคัญ 4★ เนื่องจากระบบวิเคราะห์เส้นทาง (`analyzePath`) หยุดทำงานที่กำแพง 3★ แรกที่เจอ ทำให้มองไม่เห็นกำแพงที่แข็งแกร่งกว่าด้านหลัง

**การแก้ไข:**
- ปรับปรุง `analyzePath` ให้รับค่า `minStars` เพื่อค้นหากำแพงเป้าหมายที่แข็งแกร่งตามเกณฑ์ของกลยุทธ์ (V25 ต้องการ 4★)
- เพิ่มระบบ `targetWallStars` เพื่อระบุความแข็งแกร่งของกำแพงที่เป็นตัวกำหนดเป้าหมาย
- อัปเกรด `Global TP Cap` ใน `autoTradingService.ts` ให้ตรวจสอบความแข็งแกร่งของกำแพงเป้าหมายโดยตรง หากมีการวาง TP เกินกว่าเลเวลที่ระบุ ระบบจะทำการ Cap (จำกัด) TP ไว้ที่แนวนั้นทันที

## 2. การเพิ่มประสิทธิภาพ EA-ONLY Mode (AI Hard-Skip)
**ปัญหา:** ในโหมด EA-ONLY ระบบยังมีการพยายามเรียกใช้ AI (LLM) ในขั้นตอนการเกลี่ย SL/TP (`slTpAgent`) ทำให้เกิด Error และการติด Blacklist ของโมเดลโดยไม่จำเป็น

**การแก้ไข:**
- เพิ่มสถานะ `enableAiMode` เข้าไปในแผนการคำนวณ SL/TP
- ปรับปรุง `SlTpAnalystAgent` ให้ข้ามขั้นตอนการเรียกใช้ AI (Stage 2) โดยสิ้นเชิงหากปิดโหมด AI อยู่
- ส่งผลให้ระบบประหยัดค่า API และทำงานได้รวดเร็วขึ้นในโหมดเทคนิคล้วน (Deterministic)

## 3. การแก้ปัญหา Order Sync (Timezone Fix)
**ปัญหา:** ออเดอร์ที่ปิดไปแล้วยังค้างอยู่ในสถานะ `Deferring post-mortem` เป็นเวลานาน เนื่องจากปัญหาความต่างของเขตเวลา (Timezone Offset) ระหว่าง Server และ Broker ทำให้ดึงข้อมูลประวัติการเทรดไม่เจอ

**การแก้ไข:**
- ปรับปรุง `mt5_bridge.py` ให้ดึงประวัติย้อนหลังเป็น 60 วัน และเผื่อเวลาในอนาคตไว้ 24 ชั่วโมง
- ใช้ Window การค้นหาที่กว้างขึ้นเพื่อครอบคลุมความเหลื่อมของเวลา UTC
- ผลลัพธ์: ออเดอร์ที่ปิดไปแล้วจะถูกบันทึกเข้า Journal และสรุปผลแพ้/ชนะได้ทันทีโดยไม่ค้าง

## 4. การจัดการ Zombie Processes (Bridge Stability)
**ปัญหา:** พบอาการ mt5-bridge ค้างหรือไม่มี Log วิ่ง เนื่องจากมี `python.exe` รันซ้อนกันหลายตัวและแย่ง Port 5001 กัน

**การแก้ไข:**
- เพิ่มขั้นตอนการตรวจสอบและสั่ง Kill process เดิมที่ค้างอยู่ก่อนเริ่ม Bridge ใหม่
- เพิ่มความเสถียรในการเชื่อมต่อระหว่าง Node.js และ Python ด้วยการจัดการ Port ที่สะอาดขึ้น
